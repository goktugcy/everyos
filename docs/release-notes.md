EveryOS 0.1.14 adds menu bar customization and live trash icons.

- Right-click the menu bar or press Shift+F10 to open customization, toggle indicators,
  show clock seconds or restore defaults. The editor is also available in Settings → Desktop.
- Reorder indicators from left to right and retain visibility/order across reloads in your
  own account. Existing preferences preserve their original layout.
- Trash icons show an empty bin or a bin containing paper using the current account's real
  trash listing. Delete, restore and empty operations update the icon across all desktop views.
- An unavailable listing shows an unknown state; it never pretends the trash is empty.

The publisher key, GitHub release source and default wallpaper remain unchanged. Applications
in Files, automatic hourly update notifications, passwordless EveryOS update confirmation,
automatic application defaults and port allocation, Linux account permissions and Home Assistant
integration remain included.
Application context menus and persistent installation shortcuts from 0.1.12 remain included.
Whole-item icon/name selection from 0.1.13 remains included.
