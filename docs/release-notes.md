EveryOS 0.1.42 improves file opening, media playback and window tabs.

- Files and desktop items open supported PDFs, images, videos, Markdown, JSON, text, source files,
  calendars and Excalidraw drawings in the appropriate official app. Missing apps open their
  official App Store installation details; downloading remains an explicit context-menu action.
- Gallery now supports video alongside images, including MP4 previews. Video Player accepts files
  opened from Files and the desktop, including subsequent selections in the same window.
- PDF Viewer waits for the previous document to close before loading another PDF in the same
  window. Editors retain their file limits, recovery and unsaved-change protection.
- App media streaming works during local development, including byte-range requests for video.
- Docker, System Monitor, App Store and Updates tabs keep keyboard focus visible without drawing
  a focus frame on the first mouse click; tab bars no longer show an unintended vertical scrollbar.
- The ten changed official applications advance to 1.0.1. All 29 official applications remain
  available, and the five standalone SDK packages advance together to 1.0.5.
