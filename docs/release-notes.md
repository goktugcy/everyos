EveryOS 0.1.16 adds Empty trash to the Trash icon's context menu.

- Right-click Trash on the desktop, dock or Files sidebar and choose **Empty trash**.
  Permanent deletion requires confirmation and affects only the signed-in account's trash.
- The action removes all recoverable files and folder contents across configured roots using
  existing permissioned and audited requests. Large bins continue beyond the listing limit.
- Canceling preserves the contents. Errors remain visible and dismissible; a known-empty bin
  disables the action. Locked, signed-out or no-longer-authorized sessions stop further batches.

The publisher key, GitHub release source and default wallpaper remain unchanged. Applications
in Files, automatic hourly update notifications, passwordless EveryOS update confirmation,
automatic application defaults and port allocation, Linux account permissions and Home Assistant
integration remain included.
Transparent trash artwork, live connection metadata, menu bar customization, application context
menus and persistent installation shortcuts remain included.
Whole-item icon/name selection from 0.1.13 remains included.
